# Pdfcraft: Mohammed-Moniem progress component

This independent repository contains the preserved PdfCraft engine with a bounded OCR page-selection correction and equivalent maintenance needed for its current checks. Duplicate requested pages are processed once in first-request order; page-vector reservation is bounded by the document page count. Invalid page filtering, cancellation/stale-job guards and apply checks remain in place. See [verification and limits](verification/pdf-ocr-progress.md).

The selected source passed formatting, touched-crate all-target Clippy with warnings denied, 1,364 tests with seven ignored cases, repository layer/asset checks and 33 declared WASM crate-library checks. A fresh independent source/input review and exact parent replay selected this revision. Some model/font-dependent test bodies returned early; these results do not establish complete product or format coverage.

A separate macOS ARM64 CLI archive includes the exact debug binary, default Latin OCR models and their licences. Its extracted contents passed 14 CLI commands with an empty PATH, a clean environment and OS network denial, including actual image-only OCR, save and searchable reopen. It is unsigned. Windows11, macOS Intel, native GUI, browser runtime, private-host integration and Microsoft/Acrobat parity remain unqualified for this revision.

Source, native CLI and the exact pinned PDF locale input are prepared for the `v0.1.0-pdf-ocr-progress.1` prerelease in this repository; release publication and anonymous download verification are separate gates. The full source archive does not include the Rust compiler/linker/SDK or every external build input. [OFFLINE.md](OFFLINE.md) links the preserved GitHub-hosted toolchain/vendor/support inventory. Rebuilding this PDF revision requires its PDF-specific locale commit `575cfdef63227b14daf173b8cc87928bfdfa325e`; the older Word-only locale input is insufficient.

Original MIT/Apache licences, NOTICE, attribution and contributor records are preserved. The original engine documentation is [UPSTREAM-README.md](UPSTREAM-README.md); inactive upstream CI references remain under `UPSTREAM-GITHUB/`. This is an independent progress component. The source4 baseline tag and downloads remain separate versions. [SOURCE-PROVENANCE.json](SOURCE-PROVENANCE.json) records that original source; the verification note records this later update. Changes reach `main` through an owner branch and pull request.
